# Skyrim PoE (가칭)

스카이림 SE/AE에서 Path of Exile의 빌드·파밍·엔드게임을 구현하려는 SKSE 모드입니다. 기준 게임은 Path of Exile 2입니다(2026-11-24에 PoE1에서 바꿈). 내부 이름은 `SkyrimPoE`이고 공개 제목은 아직 정하지 않았습니다.

A work-in-progress SKSE mod that aims to bring Path of Exile style builds, loot and endgame to Skyrim SE/AE, now based on Path of Exile 2. There is no public release yet, and the documents are written in Korean.

## 지금 단계

**개발 중입니다. 공개 배포판은 없고, 세이브 호환을 약속하지 않습니다.**

- 본 모드는 `plugin/`(SKSE DLL), `ui/`, `esp/`, `data/packs/`에 있습니다. PoE1(3.30) 기준으로 6단계까지 구현했고, 지금은 7단계(PoE2 전환)를 진행 중입니다.
- 빌드는 `plugin/build.bat`입니다. 기본은 **세대 1(PoE2) 개발 패키지**이고, `build.bat gen0`은 예전 PoE1 내용을 담은 **세대 0 회귀 패키지**를 만듭니다. 배치는 `build.bat [gen0] deploy "<MO2의 mods 폴더>"`이고, 게임이 켜져 있으면 배치하지 않습니다.
- 한 모드팩(AE 1.6.1170)에서만 돌려 봤고, 다른 환경에서의 동작은 확인하지 않았습니다.
- `prototypes/`에는 위험 요소를 먼저 확인한 시험용 코드와 모드가 있습니다.
- 설계 문서에는 아직 정하지 않은 항목과 실행으로 확인하지 못한 가정이 남아 있습니다. 문서 안에서 `[확정]`, `[잠정]`, `[미정]`, `미확인`으로 구분해 적습니다.

### 세대 1(PoE2) 개발 패키지의 한계

세대 1 패키지는 개발용이며 배포하지 않습니다. 지금 들어 있는 것은 PoE2 0.5 데이터로 만든 규칙·젬 목록·패시브 트리·클래스뿐입니다.

- 아이템이 없습니다. 전리품 드롭·제작·감정이 꺼져 있습니다(드롭이 꺼져 있어 젬도 떨어지지 않음).
- 지도가 없습니다. 새 지도에 들어갈 수 없고, 이미 지도 안에 있던 캐릭터는 탈출·안전 제거만 됩니다.
- 실제로 쓸 수 있는 젬은 `Spark` 하나이고, 하나를 받습니다. 새 캐릭터는 PoE 패널을 처음 열 때 받고(시작 모드가 가방을 비우는 것을 피하려고), PoE1 세이브를 정리한 캐릭터는 정리할 때 받습니다. 나머지 PoE2 젬은 "아직 구현 안 됨"으로 장착이 거부됩니다.
- 주얼은 꽂을 수 없고 이미 꽂힌 것의 회수만 됩니다. 참은 발동·충전하지 않습니다. 몬스터의 자연 승격이 없습니다.
- 처치 경험치, 패시브 트리 할당과 후회의 오브 회수는 작동합니다.

### PoE1 세이브를 세대 1 패키지로 열기 전에(백업)

- **세대 1 패키지로 PoE1(세대 0) 세이브를 불러오면 묻지 않고 바로 정리합니다.** 꽂혀 있던 젬·주얼·참은 가방으로 돌아오고, 레벨·경험치·패시브 트리·아틀라스 진행은 처음부터 시작합니다. 가방의 PoE1 물건은 지우지 않고 "(구판)" 표시로 남깁니다.
- 정리한 뒤 **저장하기 전까지는 원본 세이브 파일이 바뀌지 않습니다.** 되돌리려면 저장하지 말고 다시 불러오면 됩니다.
- 백업할 때는 세이브 폴더에서 **같은 이름의 `.ess`와 `.skse` 두 파일을 함께** 복사하세요. 한쪽만 있으면 복원되지 않습니다. MO2에서 프로필 전용 세이브를 쓰면 세이브 폴더는 `<MO2>\profiles\<프로필>\saves`입니다.
- PoE1로 돌아가려면 세대 0 패키지(`build.bat gen0 deploy "<MO2의 mods 폴더>"`)를 배치하고 백업한 세이브를 쓰세요. 세대 0 패키지는 세대 1 세이브를 **보존 모드**로 엽니다(모드 기록을 그대로 두고 모드 기능은 멈춤).
- 7단계 G1 이전에 빌드한 DLL은 세대 1 세이브의 새 기록을 알아보지 못해 보존하지 못합니다. 그 DLL로 세대 1 세이브를 열고 저장하지 마세요.

| `prototypes/07-…`~`14-…` | 피해 측정, 주문 등록, 적 조사, 주 갱신, 던전 복제, 지도 실험 등 그 밖의 시험 |

## 저장소에 없는 것

- 다른 사람이 만든 애니메이션 파일(HKX)과 그 복사본은 넣지 않았습니다. 프로토타입 1과 3을 그대로 재현하려면 해당 파일을 따로 구해야 합니다.
- Path of Exile의 게임 파일과 Path of Building의 데이터는 들어 있지 않습니다.
- 문서에 적힌 `G:\...` 같은 경로는 작업한 컴퓨터의 경로입니다. 사용자 이름은 `USERNAME`으로 바꿔 적었습니다.

## 라이선스

소스 코드는 [GPL-3.0](LICENSE)입니다.

프로토타입 2는 엔진의 근접 타격 함수의 주소와 인자를 [Precision](https://github.com/ersh1/Precision)(ersh1, GPL-3.0)의 소스에서 확인해 씁니다. 빌드에는 [CommonLibSSE-NG](https://github.com/alandtse/CommonLibSSE-NG)(alandtse, GPL-3.0-or-later와 모딩 예외)가 필요합니다. 프로토타입 1·3·4는 v9.0.2로 빌드했고 그 판은 이 저장소에 포함하지 않았습니다. 프로토타입 2·5(2026-11-19부터)와 6 이후는 아래의 v16.4.0으로 빌드합니다. 본 모드는 v16.4.0으로 빌드하기로 했고, 그 판을 `external/CommonLibSSE-NG`에 서브모듈로 두었습니다(`git submodule update --init external/CommonLibSSE-NG`로 받습니다).
