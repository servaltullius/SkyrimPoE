### 1.4 포털 거래·사망 가로채기 (검수 C-2 반영)
- **포털 거래(#42, PoE1 6포털 표준)**: 일반 지도 6포털(입장 -1, 정상 귀환 0, 재입장 -1, 사망 탈출 자체는 이중 차감 없이 안전 귀환·남은 포털 0에서 사망 시 즉시 실패 종료 = 총 6회 진입/목숨), 4차 결투장 1포털(입장 시 0 잔여, 단판). 추적 지도 아이템 소비는 `SaveLoad::RunSerializedTransaction` 내부에서 `ItemTracker::FindExtraListByKey → RemoveItem(extra) → ItemTracker::RemoveByKey`로 원자 처리(일반 지도는 `UniqueIdUtil::RemovePlainItem`).
- **사망 가로채기(#41, 검수 C-2 정정)**:
  - **원자 스레드 안전**: `MapDeviceRuntime::Tick`(주 갱신)이 `std::atomic_bool g_playerInActiveMapCell`을 갱신하며, 전투 훅(워커 스레드 가능)은 원자 플래그만 읽는다.
  - **정확한 훅 자리**: 물리 `CombatHooks::ProcessApplyHit` (**`siteIdx == 7` 포함** `g_deathEscapeInFlight` 가드) + 마법 **`CombatHooks::ProcessMagicModifyActorValue` (`ValueModifierEffect::ModifyActorValue` ID 35086, `self->spell == nullptr` 포함)** — `HandleHealthDamage`가 아닌 체력 차감 **전** 자리에서 처리!
  - **난이도 배율(`diffMult`) 반영**: `effectiveDmg = rawDmg * diffMult`로 치명 판정(`curHp - effectiveDmg <= 1.0f`)하고, 치명 발동(또는 `g_deathEscapeInFlight`·탈출 직후 무적 창 활성) 시 **피해를 `0.0f`로 완전 무효화**한다.
  - **중복 차감 차단**: `g_deathEscapeInFlight`를 세운 뒤 주 갱신에서 `AilmentRuntime::ClearPlayerAilments()` + 체력/매지카/스태미나 회복 + 잔여 포털 확인(0이면 실패 종료, >0이면 재입장 가능 유지) + 귀환 `MovePlayerToSpace` 수행. `g_deathEscapeInFlight`는 **플레이어가 지도 셀을 실제로 벗어난 뒤 `1.5s` 경과 후**(또는 재입장/`OnRevert` 시)에만 해제한다.
  - **명시적 한계**: `KillImpl` 직접 즉사·킬무브·타 사망 대체 모드 선행 훅은 범위 밖이며 `MapDeathInterceptEnabled` INI 토글 제공.

### 1.5 4차 전직 3페이즈 보스전·아틀라스 +24 패시브·정신력 220 (검수 C-5, C-6 반영)
- **3페이즈 보스 게이트 & 동료 타격 가드 (검수 C-5 반영)**:
  - `MonsterRuntime::ApplyPlayerHitToMonster` + `CombatHooks::ProcessApplyHit`(동료 `aggressor != player` → `target == arenaBoss` 포함)에서:
    - 전환 무적(`invulnRemainingSec > 0`) 중이면 피해 `0.0`.
    - Phase 1은 보스 체력이 `maxHp * 0.665` 미만으로, Phase 2는 `maxHp * 0.335` 미만으로 내려가지 않도록 **동기 클램프**(`fDiffMultHPByPC` 반영) 후 주 갱신 큐로 페이즈 전환(`SPOE_Vfx_FireBurst` + 속성 추가 + 쫄 2체 소환 + `0.8s` 무적) 예약. Phase 3에서만 처치 허용.
- **패시브 +24점(총 123점) & 전직 8/8 & 정신력 220 (검수 C-6, Minor 1 반영)**:
  - `PassiveTree::ComputeAvailableNormalPoints(..., std::uint16_t atlasCompletedTierMask = 0)` 및 내부/외부 모든 호출부(`AllocatePath`, `SelectMastery`, `RefundNode`, `RefundAll`, `SaveLoad`, `CraftingRuntime`, `UiBridge`, `AutoTest`)에 `atlasCompletedTierMask` 일괄 연결.
  - `milestonePoints = popcount(bitmask & 0xFu) * 2` (최대 8) + `atlasTierPoints = popcount(atlasCompletedTierMask)` (최대 16) = **+24점** → Lv100 합계 **123점**.
  - `0x7u → 0xFu` / `3u → 4u` 일괄 갱신(`PassiveTree.cpp`, `SaveLoad.cpp`, `StatEngine.h/.cpp`, `CraftingRuntime.cpp`, `Types.h`, `ui/tree.js`), 기존 `test_passive_tree.cpp` 음수 잔액 테스트 2건의 기대치 정합 갱신(음수 가드 검증 목적 유지).

### 1.6 `WorldDropTracker` 6단계 통합 & 인게임 안전 제거 정리 절차 (검수 C-4, M-2 반영)
- **`WorldDropTracker` (검수 M-2)**: `IsSkyrimPoELootForm`/`IsBeamBaseForm`/`SweepOrphanBeamsNearPlayer`에 `0x8AE..0x8BF` 18폼 등록 + 활성 지도 셀 소속 드랍은 지도가 활성인 동안 `zoneChanged` 자동 회수/삭제 보류(지도 종료 시 정리).
