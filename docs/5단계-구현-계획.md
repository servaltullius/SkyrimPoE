### 1.1 정신력(Spirit) & 지속 버프 9종 (결정 161)
- 자원명: **정신력(Spirit)**.
- 최대치 공식: `maxSpirit = 100 + (이정표 1~3차 달성 수 × 30) + 장비/고유/주얼의 flatSpirit` (기본 100 → 3차 이정표 후 190 + 장비).
  - `DeathListener.cpp`에서 보스 이정표가 새로 해금되면(`unlockedTier > 0`) 레벨업 여부와 무관하게 즉시 `SaveLoad::SyncStateToStatEngine()`을 호출해 `+30` 정신력을 즉시 반영한다.
- 비용 환산 (PoB 2.68.1 `Data/Skills/*.lua` 실측 대조):
  - **50 정신력 오라 6종**: `Determination`(고정 방어도 + MORE 방어도), `Grace`(고정 회피 + MORE 회피), `Hatred`(물리→냉기 추가 피해, PoE 3.30 PoB 2.68.1 기준 MORE 냉기 없음), `Wrath`(번개 추가 피해 + MORE 주문 번개), `Anger`(화염 추가 피해), `PurityOfElements`(모든 원소 저항 + 원소 상태이상 면역)
  - **35 정신력 오라 1종**: `Discipline`(PoB 2.68.1 실측 `manaReservationPercent = 35` → 35 정신력, 고정 최대 ES + ES 재충전 속도)
  - **25 정신력 전령 2종**: `HeraldOfIce`(냉기 추가 피해 + 냉각/빙결 적 처치 시 냉기 폭발), `HeraldOfAsh`(물리→화염 추가 피해 + 처치 시 과잉 피해 기반 화염 폭발)
- 활성화·중복·불변식 규칙:
  - `Core::GemKind`에 `Aura`, `Herald`, `Guard`를 추가하고, `DataPack` 젬 정의에 `spiritCost` 필드를 컴파일한다.
  - 스킬 탭(`K`)에서 장착된 오라/전령 젬을 클릭 토글(`activeAuraMask` 비트마스크). 잔여 정신력이 부족하면 토글 ON 거절.
  - 동일 오라/전령 `gemId`가 여러 슬롯에 켜져 있으면 최고 레벨 1개만 적용한다.
  - 장비 요구치 미달(`Prism Guardian` 비활성 등)로 `maxSpirit`이 줄어 `reservedSpirit > maxSpirit`가 되면 `StatEngine::ComputeSnapshotLocked` 안에서 뒷슬롯 오라부터 자동 비활성화해 `snap.effectiveActiveAuraMask`와 `reservedSpirit <= maxSpirit` 불변식을 항상 유지한다.

### 1.2 논리 10칸(가상 반지2·벨트) + 참(Charms) + 패시브 주얼 (결정 162, 164)
- **논리 10칸 (`Core::EquipSlot` 8→10 확장: `Ring2`, `Belt` 추가)**:

    - 미추적 일반(`uniqueId == 0`) 반지 장착 시 `ItemTracker::EnsureUniqueId()`로 스택 1개 분리 + UID 발급 후 추적.
    - 이중 장착 차단: `EquipmentSync::RefreshFromPlayerNow()`에서 `Ring1.key == Ring2.key`(가상 반지2를 스카이림 인벤토리에서 물리 착용) 또는 가방 이탈을 감지하면 `Ring2`를 자동 탈착한다.

    - **임플리싯(Implicit) 분리**: `PoEItemRecord`에 `std::vector<RolledAffix> implicitAffixes;`를 분리 보관한다(`'ITEM'` v2 직렬화). `Alteration`/`Chaos`/`Scouring`은 `affixes`만 조작해 벨트·고유 아이템의 임플리싯이 소멸하거나 접두/접미 개수 계산이 망가지는 일을 원천 차단한다.
- **벨트 참(Charms, 1~3칸)**:
  - 개방 칸 수: 벨트 미착용 = `0`, 일반/T1~T3 매직 벨트 = `1`, T4~T5 매직 또는 T1~T3 희귀 벨트 = `2`, T4~T5 희귀·`Stygian Vise`·고유 벨트 = `3`.
  - 핵심 참 6종(`MiscItem`, 자동 발동·수동 키 없음):
    1. `RubyCharm`: 화염 피격 시 자동 발동 (4초간 화염 저항 +25%, 최대 화염 저항 +2%)
    2. `SapphireCharm`: 냉기 피격 시 자동 발동 (4초간 냉기 저항 +25%, 최대 냉기 저항 +2%)
    3. `TopazCharm`: 번개 피격 시 자동 발동 (4초간 번개 저항 +25%, 최대 번개 저항 +2%)
    4. `AmethystCharm`: 카오스 피격 시 자동 발동 (4초간 카오스 저항 +25%)
    5. `ThawingStaunchingCharm`(정화의 참): 빙결·냉각·출혈 피격/적용 시 즉시 해제 + 4초간 빙결·출혈 면역
    6. `GuardCrisisCharm`(수호의 참): 피격 후 예상 체력이 최대의 40% 이하일 때 자동 발동 (4초간 물리 피해 감소 +15%, 고정 방어도 +600)
  - 충전 규칙: 최대 `40`, 발동 소모 `20`, 처치 보상 충족 적 처치 시 일반 `+2` / 매직 `+4` / 레어 `+8` / 보스 `+15` 충전(결정 113~115 경로). 상시 HUD에 참 충전 표시.
- **패시브 주얼 소켓 장착 (결정 105 젬 소유 방식 통일)**:
  - 주얼 베이스 3종(`Crimson Jewel` `{jewel, not_dex, not_int}`, `Viridian Jewel` `{jewel, not_str, not_int}`, `Cobalt Jewel` `{jewel, not_str, not_dex}` — PoB 2.68.1 `Data/Bases/jewel.lua` 실측 태그 일치).
  - PoB 2.68.1 `Data/ModJewel.lua`에서 `type in ("Prefix", "Suffix")`만 추출(`Corrupted`·`abyss_jewel` 제외), 주얼 제작 상한은 **매직 1~2(1P/1S), 희귀 3~4(최대 2접두/2접미)**.

  - **`StatEngine` 고정점 순서**: `base + passives + socketedJewels`를 **10칸 장비 고정점 루프 진입 전**에 합산해 주얼 능력치가 장비 요구치를 충족할 수 있게 한다.

### 1.3 스킬·투사체·대리 주문 손 시전·가드 파워·상태이상 5종 (결정 163)

  - **오라·전령(9종)** + **즉발 가드 파워(1종)**: `MoltenShell`(포효 키 대리 파워, 3초간 현재 방어도의 10%[최대 PoE 5000] 보호막으로 **타격 피해의 75% 흡수**[PoB 2.68.1 실측, DoT 제외], 버프 파괴/만료 시 4초 쿨다운 시작 및 주변 반사 화염 폭발)
  - **신규 19종 젬 획득 경로**: `FormIds::kAllGemForms` 28종 통합 테이블 확장 + 처치 드랍 풀에 저확률 젬 드랍 추가 + 기존 4단계 세이브 및 새 게임 진입 시 `starterStage5GemsGiven` 플래그로 `SkyrimPoE.ini` `GiveStarterGems=true` 환경에서 5단계 핵심 체험 젬 지급(중복 방지).
- **대리 주문·파워 손 시전 계약 (`ProxySpellRuntime`, 프로토타입 10 검증 + 결정 90·91)**:
  - **안 A 채택**: `SPOE_ProxySpellEffect`(`0x800`)를 `TargetType=Self` (`CastType=FireAndForget`, `Delivery=Self`, 무투사체)로 설정해 9개 슬롯 대리 주문(`SPOE_ProxySpell_1..9`)이 모두 확실히 `MagicCaster::Fire → SpellCast(doCast=true)`까지 도달하게 한다.
  - `ActorMagicCaster::CheckCast`(vtable `0x0A`) 및 `SpellCast`(vtable `0x09`)를 원본 포인터 체인 방식으로 훅한다(DMMF 공존).
  - **멀티스레드 안전 + 우회 차단(결정 90)**: `CheckCast`/`SpellCast`는 7개 스레드에서 호출되므로, `SpellCast(doCast=true)`에서는 직전 `CheckCast` 관문 통과 플래그를 확인한 뒤 `(slotIndex, aimPos, aimDir, dualCast)`만 캡처해 **`CommandQueue` 주 갱신 스레드로 이연 실행**한다.
  - **세이브 간 레코드 초기화·중복 이름(결정 91)**: `OnRevert` 및 `PostLoadInit`에서 18개 대리 레코드(`ProxySpell_1..9`, `ProxyPower_1..9`)의 이름·비용·시전 시간을 일괄 초기화·재동기화하며, 같은 이름 주문이 2개 이상이면 `[2]`·`[3]` 접미사를 붙인다.
  - **메뉴 질의 억제**: `CheckCast`가 `MagicMenu`/`FavoritesMenu` 등에서 호출될 때는 `originalResult == true && !ui->GameIsPaused()` + 1초 스로틀 조건에서만 쿨다운 알림을 띄운다.
  - `SPOE_ProxyPower_1..9`(`MoltenShell`): `CheckCast`에서 쿨다운·요구치·매지카(또는 Blood Magic 체력) 확인 후 `SpellCast`에서 매지카/체력 차감 및 보호막 발동.
- **투사체 런타임 계약 (`ProjectileRuntime`, 프로토타입 6 검증 + 결정 111)**:
  - 무해 연출용 `BGSProjectile` 3종(`SPOE_Proj_Fireball`, `FreezingPulse`, `Spark`)을 `Projectile::Launch`로 발사하고, **`RE::VTABLE_MissileProjectile[0]` vtable `0xBD` (`RE::MissileProjectile::AddImpact`)**에 체인 훅을 건다.
  - **엔진 함정 방어**:
    1. `AddImpact` 3번째 인자 `a_velocity`는 **진행 방향 반대 단위 벡터**이므로 반드시 `dir = -a_velocity` 부호 반전 후 정규화한다.
    2. 투사체당 `impacted` 원자 플래그로 다중 `AddImpact` 중복 피해를 1회로 차단한다.
    3. **관통·분기·연쇄 모든 재발사**에서 `shooter = hitActor`, `origin = hitPos + dir * kRelaunchClearance + {0, 0, kRelaunchLift}`를 적용해 즉시 재충돌 및 지형 걸림을 방지한다(프로토타입 6 3차 검증).
    4. **결정 111(아군·비조준 비적대 통과)**: 동료·소환수·비적대 중립 NPC 적중 시 피해 `0` + 남은 관통/분기/연쇄 횟수를 **소모하지 않고** `shooter = hitActor`로 동일 방향 통과 재발사(최대 4홉 상한).
    5. `AddImpact`에서 `DoDamage`/재발사를 직접 호출하지 않고, 메타를 즉시 소비한 뒤 **`CommandQueue` 주 갱신 스레드**로 이연 실행한다.
- **핵심 상태이상 5종 (`AilmentSystem` + `AilmentRuntime`)**:
  - **점화(Ignite)**: 화염 치명타/점화 확률 → 4초 화염 DoT(초당 적중 화염 피해 90%, 최고 1개).
  - **냉각(Chill)**: 냉기 피해 비례 2초 이동속도 감속(`5~30%`; 행동속도 저하는 바닐라 Havok 제약으로 미구현).
  - **빙결(Freeze)**: 냉기 치명타/빙결 확률 → 일반/매직/레어 잡몹 0.3~1.5초 `SpeedMult -95` + 최초 빙결 시 `staggerStart` 경직 1회(완전 행동/시전 정지 빙결은 바닐라 Havok 제약으로 미구현), **보스·드래곤은 최대 냉각(30%)으로 안전 완화**.
  - **감전(Shock)**: 번개 치명타/감전 확률 → 2초 받는 모든 PoE 피해 `+5~50%` 증폭.
  - **출혈(Bleed) / 중독(Poison)**: 출혈 5초 DoT(이동 시 3배, PoB 2.68.1 `CalcSetup.lua:651` 기준, 최고 1개), 중독 2초 중첩 DoT(최대 20중첩).
  - **안전한 `SpeedMult` 적용**: `kTemporary` `SpeedMult` 변경 시 `CarryWeight` 0.01 미세 펄스로 즉시 갱신하고, 액터별 적용 델타를 추적해 만료·사망·`TESResetEvent`·`OnRevert` 시 정확히 원복한다(플레이어 `kPermanent` 수정 절대 금지). DoT는 주 갱신 `0.25s` 틱으로 안전 실행.

### 1.4 매직·레어 몬스터 승격 & PoE1 고유 아이템 16종 (결정 164)
- **매직·레어 몬스터 승격 (`MonsterModSystem` + `MonsterRuntime`)**:
  - 주 갱신 스레드에서 `0.5s` 주기로 `RE::ProcessLists::GetSingleton()->highActorHandles`의 전투 중 적대 액터를 사전 승격(워커 스레드 `CombatHooks`에서는 읽기 전용 조회 + 적 ES 차감만 원자 처리).
  - **제외 대상 전수 보호**: `IsEssential() || IsProtected() || IsPlayerTeammate() || IsSummoned() || AsActorState()->IsReanimated() || IsCommandedActor() || IsGhost() || IsChild() || IsDead() || !IsHostileToActor(player)`.
  - 승격 확률(INI 조절): 매직 `12%`(속성 1개, 받는 피해 `×0.75`, 주는 피해 `×1.20`, 드랍 `×1.6`), 레어 `4%`(속성 2~3개, 받는 피해 `×0.55`, 주는 피해 `×1.35`, 드랍 `×3.0` + 고유 드랍 보너스).
  - 속성 12종: `Hasted`, `Armoured`, `FireResistant`, `ColdResistant`, `LightningResistant`, `ChaosResistant`, `EnergyShielded`(적 ES 풀 부여), `ExtraPhysical`, `ExtraFire`, `ExtraCold`, `ExtraLightning`, `Deadly`.

## 2. ESP 폼 확장 계획 (`esp/SkyrimPoE.esp`)

- 기존 `SPOE_ProxySpellEffect`(`0x000800`): `TargetType=Self`로 갱신(안 A 대리 주문 손 시전 보장).
- 5단계 신규 49폼 (`0x00087D..0x0008AD`, 총 **174 / 2,048 ESL 폼**, 8.5%):
  - `0x00087D..0x00088F` (19): 신규 젬 `MiscItem` 19종
  - `0x000890..0x000894` (5): 벨트 베이스 `MiscItem` 5종
  - `0x000895..0x00089E` (10): 벨트 봉인 토큰 `MiscItem` 10종 (T1~T5 × 매직/희귀)
  - `0x00089F..0x0008A1` (3): 주얼 베이스 `MiscItem` 3종 (`Crimson/Viridian/Cobalt`)
  - `0x0008A2..0x0008A7` (6): 참(Charms) `MiscItem` 6종
  - `0x0008A8..0x0008AA` (3): 무해 연출 `BGSProjectile` 3종 (`SPOE_Proj_Fireball`, `FreezingPulse`, `Spark`)
  - `0x0008AB` (1): `BGSExplosion` 1종 (`SPOE_Vfx_FireBurst`)
  - `0x0008AC` (1): `SPOE_Tok_Unique` (`MiscItem` — 고유 봉인 토큰)
  - `0x0008AD` (1): `SPOE_LootBeam_Unique` (`Static` — 고유 전리품 전용 빛기둥)
- `WorldDropTracker::IsSkyrimPoELootForm()` 및 `IsBeamBaseForm()`에 벨트 토큰 10종, 고유 토큰, 주얼 3종, 참 6종, 고유 빛기둥을 모두 등록해 바닥 드랍 회수·고아 스윕 누락을 차단한다.

## 3. 코세이브 확장 (`SaveLoad`) — 4단계 세이브 하위 호환 설계(이전 판 실게임 미확인)

- `'ITEM'` **v2** (v1·v2 모두 로드 허용): `ItemRarity::Unique(3)`, `TokenSlotGroup::Belt(8)/Jewel(9)`, `uniqueId` 문자열, `implicitAffixes` 벡터 추가.
- `'SPRT'` **v1** (신규): `uint16_t activeAuraMask`, `bool starterStage5GemsGiven`.
- `'GEAR'` **v1** (신규):
  - 가상 `Ring2` / `Belt` (`InventoryItemKey` + `baseFormId`, 로드 시 `ownerFormId`·`baseFormId` 모두 `ResolveFormID()` 수행)
  - 참 3칸 (`CharmKind` + `charges`)
  - 패시브 주얼 소켓 맵(`nodeId -> { baseFormId, PoEItemRecord }`, 결정 105 직접 소유 모델)
- `OnSave`의 `g_txMutex` 구간에서 `'SPOE'`, `'GKEY'`, `'TREE'`, `'ITEM'`, `'WDRP'`, `'SPRT'`, `'GEAR'`를 단일 원자 스냅샷으로 저장하고, `OnRevert` 콜백에 5단계 런타임 5종 초기화를 모두 등록한다.
