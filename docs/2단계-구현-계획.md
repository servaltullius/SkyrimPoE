# Skyrim PoE — 2단계 구현 계획 (뼈대와 첫 조각)

작성일: 2026-11-19 (Gemini 작성, 독립 검수 반영, 사용자 승인 완료 — 2단계 M1~M9 구현·독립 검수 3회·빌드·ctest·패키징 완료, 인게임 통합 시험 대기)
기준 문서: `docs/통합-설계서.md`, `docs/설계-현황.md` (결정 1~150)

## 1. 목표와 범위

2단계(통합 설계서 15장 2번)의 목표는 **"사이클론으로 적을 잡으며 치명타 시 시전이 발동하고 유배자 레벨과 장착 젬이 오르는"** 첫 플레이 가능 조각을 본 모드(`SkyrimPoE`) 코드베이스로 완성하는 것입니다.

### 1.1 2단계에 포함하는 것
- 본 모드 SKSE 플러그인(`SkyrimPoE.dll`) 빌드 환경(`CommonLibSSE-NG v16.4.0`, AE 1.6.1170 우선, `REL::RelocationID` 겸용 틀 + 미확인 SE 오프셋 안전 가드 `[확정 60, 141]`)
- PoB 2.68.1 (PoE 3.30) 최소 변환 도구 및 데이터/언어 팩(`statInterpolation == 3` 보간, `Data/ModExplicit.lua` 저항 등급, `requireSkillTypes` RPN 논리식 포함 `[확정 34, 35, 104]`, `[잠정 31, 32]`)
- 주 갱신 훅(`AE 36544+0x160` 체인, `void(RE::Main*)`), FIFO 예약 큐, 로드 세대·코세이브(`SPOE`), 3층 스탯 집계기·불변 사본(`[확정 117~124, 138~140]`, `[잠정 137]`)
- 주는 피해·받는 피해 PoE 수식 및 환산(`K=75`, 기준 타격률 `1.6/s`, `Dref=10.7`, 기대 마나 `(34+6L)×(1+I_마나)`, 받는 타격 전체 7자리 + 받는 마법 23자리 + 폭발 비율 + 난이도 배율 보정 에너지 실드 풀·2초 지연 33%/s 재충전 `[확정 62, 64~71, 73~87, 92~94, 125, 142~144]`)
- 표적 선택·피해 허용·적대 판정(`IsHostileToActor(player)` 기준, 번지는 피해만 적대 재검사, 직격 예외, 아군 제외 `[확정 52, 53, 55, 109~112, 133, 139, 148]`)
- 사이클론(OAR `Variable09` 정지 자세 클립 + DLL `NPC` 노드 회전/범위 타격 + 좌클릭 홀드 강공격 + 매지카 결제 + 상태표·경직·프렌지 양보 `[확정 48, 50, 54, 56, 63, 95~98, 122, 128, 150]`, `[잠정 49, 99]`)
- 보조 젬 5종(수치·범위 조절) + 치명타 시 시전(CoC) 발동 젬(공격 비용 ×1.2, 주문 피해 감폭 −19%~−10%) + 즉발 범위 주문 2종(`Ice Nova`, `Shock Nova`)의 DLL 직접 발동·무해 `EXPL` 연출(`[확정 51, 100~103, 126~127, 129~132, 145]`)
- 처치 추적기(피해 직전 적대 스냅샷 + `Character::HandleHealthDamage` 0x104 통합 기여 확정으로 바닐라 평타·주문·작업 큐 지연 타격까지 포괄) + 유배자 레벨 1~100 경험치 + 장착 젬 경험치·레벨업(1~20)(`[확정 17, 108, 113~116, 134~136, 138, 140, 146~149]`, `[잠정 137]`)
- 젬 인벤토리 고유 ID 추적 최소판(결정 59의 인벤토리/컨테이너 이동·저장 왕복 추적 — 칸에서 뺀 데이터 젬을 다시 장착해도 레벨·보조·담긴 주문 유지 `[확정 59, 105~108, 145]`)
- Prisma UI 단일 뷰: 표시 전용 HUD(패널 닫힘 시 루프 중지·값 변경 시만 푸시) + 최소 스킬 화면(9칸 슬롯, 젬·보조·발동 주문 장착 거래, 능력치 요약, 포커스·지연 키 차단 훅·키 뗌 삼킴 `[확정 23, 61, 86, 88, 120]`, `[잠정 24, 137]`)
- `SkyrimPoE.esp` (ESL 플래그): 9칸 대리 주문/파워 18개(세이브 FormID 고정용 뼈대 `[확정 88, 89]`), 초기 젬 9종 `MISC`, `Ice Nova`/`Shock Nova`용 무해 `EXPL` 2종

### 1.2 2단계에서 의도적으로 제외하는 것 (후속 단계)
- **3단계**: 패시브 트리 UI, SimpleIME 2.2.1 한글 검색창 다리(2단계 최소 스킬 화면에는 글자 입력칸 없음), 클래스 선택, 노드 할당/회수, 마스터리, 주얼, 스탯 매핑 대량 확장, 능력치 요구치 미달 비활성화
- **4단계**: 장비 어픽스, 봉인 토큰·감정, 오브 제작, 바닥 드랍, Grid Inventory/SkyUI 툴팁 연동, 결정 59의 바닥 경로·여러 개 줍기·저장 경계(5장 47번 (26)~(28))
- **5단계**: 주문 손 시전(대리 주문 실행 중 갱신 + 결정 90 `CheckCast`/`Fire` 관문 훅), 투사체 관통·연쇄·분기·귀환, 지속 버프(전용 자원), 참, 2번째 반지·벨트 칸, 야생 매직·레어 승격
- **6단계**: 은신처, 지도 장치, 복제 던전, 1~4차 전직 시련·결투장, 보스 업적 24점 지급
- **배포 전**: SE 1.5.97 주소 일괄 대조(`[확정 141]`), 다른 모드 목록에서의 `K`/`Dref` 재측정(`[확정 40]`), 자체 제작 아이콘·최종 회전 모션 다듬기, OAR 조건의 `Variable09`→OAR API 전환

## 3. 2단계 초기 젬 목록 (PoB 2.68.1 `Data/Gems.lua` 및 `Data/Skills/*.lua` 대조 완료)

| 구분 | `grantedEffectId` | 한글명 | 2단계 역할 |
| --- | --- | --- | --- |
| 채널링 공격 | `Cyclone` | 사이클론 | 좌클릭 홀드 강공격, 공속 ×3, 매지카 차감, 범위 근접 타격 |
| 발동 젬 | `SupportCastOnCriticalStrike` (`SupportCastOnCritTriggered`) | 치명타 시 시전 | 공격 칸 1개 연결(공격 비용 ×1.2), 소켓 수만큼 주문 장착, 0.15초 개별 쿨다운, 주문 비용 ×1.2·주문 피해 감폭 −19%~−10% |
| 발동 주문 1 | `IceNova` | 얼음 회오리 | 즉발 범위 냉기 피해(DLL `DoDamage` + 무해 `EXPL` 연출, 2단계는 CoC 소켓 전용) |
| 발동 주문 2 | `ShockNova` | 충격 회오리 | 즉발 범위 번개 피해(순환 시전·개별 쿨다운·속성별 계산 검증, 2단계는 CoC 소켓 전용) |
| 보조 1 | `SupportIncreasedCriticalStrikes` | 치명타 확률 증가 | 기본 치명타 확률 + 증가율 (CoC 발동 체감 확인) |
| 보조 2 | `SupportMeleePhysicalDamage` | 근접 물리 피해 | 근접 물리 피해 증폭 + 공격 속도 감폭 (증폭/공속 반영 검증) |
| 보조 3 | `SupportBrutality` | 포악함 | 물리 피해 증폭 + 원소/카오스 피해 불가 (속성 제약 검증) |
| 보조 4 | `SupportIncreasedAreaOfEffect` | 효과 범위 증가 | 사이클론/범위 주문 반경 증가 |
| 보조 5 | `SupportConcentratedEffect` | 집중 효과 | 범위 피해 증폭 + 반경 감소 |

- **2단계 젬 획득 경로 (Gemini 제안, 사용자 확인 전)**: 4단계(드랍·상인) 전이므로, 2단계에서는 최초 로드 시 테스트용 젬 9종을 플레이어 인벤토리에 1회 지급하는 INI 옵션(`GiveStarterGems = true` 기본값, 코세이브에 지급 완료 플래그 기록, 4단계에서 `false` 전환)으로 바로 시험할 수 있게 합니다.
- **초기 소켓 수 임시 고정 (Gemini 제안, 사용자 확인 전)**: 5장 26번(소켓 확장 오브)은 4단계 영역이므로, 2단계에서는 사이클론·발동 젬·주문 젬의 보조 소켓을 기본 3칸(INI 설정 가능, 최대 5칸)으로 임시 고정해 보조 5종·주문 2종 조합을 바로 시험합니다.
