### 3.2 HEDR 1.70

- 지금 HEDR은 모두 1.71입니다.
  - `esp/SkyrimPoE.esp`: ESL, 192폼 + 6그룹 = 헤더 집계 198, 로컬 ID 0x800~0x8BF(1.70 ESL 범위 0x800~0xFFF 안).
  - `SkyrimPoE_Maps.esp`: 정규 ESP, 4,313폼 + 26그룹 = 4,339, 로컬 ID 0x800~0x88BF(정규라 ESL 상한과 무관).
- 1.70으로 내리는 이유는 SE에서 BEES 없이 라이트 플러그인을 쓰게 하려는 것입니다(설계-현황 7장).
- 코어 ESP는 houseCARL이 `esp/records.json`으로 만듭니다. 헤더 판을 정하는 설정은 찾지 못했습니다(미확인). 재생성 때 1.71로 돌아가지 않게 생성 절차에 묶어야 합니다.
- 지도 ESP는 `tools/dungeon-clone`(Mutagen 0.54.4)이 만듭니다. 고정된 Mutagen에는 `ModHeader.Stats.Version`의 공개 setter가 있습니다. 실제로 쓰고 다시 읽은 결과는 미확인입니다.
- 1.71을 기대하는 곳: `tools/dungeon-clone/DungeonClone/Verify.cs:19,440`, `tools/dungeon-clone/README.md:154`.
- 지도 ESP를 바꾸면 함께 바뀌는 것: 목록 파일의 `espSha256`(빌더가 기록한 바이트에서 만듦, `Program.cs:137`), `plugin/tests/maps_format4.json`, CMake `VerifyMapsPack`(패키징 전후 대조), 런타임 SHA-256 대조(`MapPackRuntime.cpp:177`). CMake와 런타임의 대조는 "구판 ESP + 구판 목록"을 함께 넣어도 통과하므로 HEDR 자체는 따로 검사해야 합니다.
- 지도 팩 `packVersion=1`과 던전 키·FormID를 보존해야 기존 활성 회차가 이어집니다. 판을 올리면 불러올 때 호환 불가 회차로 정리됩니다(`MapPack.cpp:215`, `MapDeviceRuntime.cpp:3889`).
