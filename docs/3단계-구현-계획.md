## 1. 3단계 목표와 완료 정의 (DoD)

3단계가 끝나면 플레이어는 스카이림 AE 1.6.1170 게임 안에서 다음 루프를 끝까지 수행할 수 있어야 합니다.
1. `P` 키(또는 `K` 패널 상단 탭)로 **패시브 스킬 트리** 화면을 열어 **7개 시작 클래스 중 하나를 선택**하고(초기 미선택 시 첫 오픈에서 선택, 할당 노드 0개 시 재선택 가능),
2. **원본 규모 PoE 3.30 패시브 트리**(일반 트리 + 기본 전직 19종, 1080p 타일 Canvas 2D 렌더, SimpleIME 2.2.1 한글 검색)에서 **호버 최단 경로 미리보기·클릭 할당·무료 회수·마스터리 선택·전직 선택/할당**을 수행하며,
3. 할당한 패시브 노드·마스터리·핵심 키스톤의 스탯이 **즉시 `StatEngine` → 스카이림 최대 체력/매지카/에너지 실드·방어/저항(최대 저항 상한 포함)·사이클론/CoC 피해·치명타·공속·범위·HUD**에 반영되고,
4. **1~3차 보스 처치 이정표(전직 포인트 6점)**가 `DeathListener`에서 세이브당 1회(Lv.100·XP 0에서도 정상) 기록되며,
5. **코세이브 `'TREE'` 레코드**에 클래스·전직·할당 노드·마스터리·이정표가 안전하게 저장·복원(기존 2단계 세이브 하위 호환 유지)되고,
6. **게임 밖 단위 테스트(Python + C++ `ctest`)** 및 **AE 1.6.1170 인게임 자동 통합 검증(AutoTest 2단계 A·B·C 회귀 + 3단계 D 시나리오)**이 크래시 0으로 전부 통과합니다.

## 4. 마일스톤별 세부 구현 계획 (S3-M1 ~ S3-M7)

### S3-M1. PoB 2.68.1 `3_30/tree.lua` 컴파일러 & 한글화 병합
- **입력**: `G:\poe\PathOfBuilding-2.68.1\TreeData\3_30\tree.lua` + 한글 참조 `G:\poe\POE1 한글 POB (2025.10.31)\Data\Translate\ko-KR\{tree_dn.csv, tree_sd.csv, passiveTree.csv, statDescriptions.csv}`.
- **필터링 & 정규화 규칙 (검수 C2, C3, M6, m2 반영)**:
  1. `root`, `group` 미존재 노드, `isProxy == true`(3.30 Putrid Seed 포함), `isBloodline == true`(147개), `isBlighted == true`(성유 전용 고립 30개) 제외.
  2. `ascendancyName`이 있는 노드는 기본 전직 19종 `id` 집합(`Ascendant`, `Juggernaut`, `Berserker`, `Chieftain`, `Raider`, `Deadeye`, `Pathfinder`, `Occultist`, `Elementalist`, `Necromancer`, `Slayer`, `Gladiator`, `Champion`, `Inquisitor`, `Hierophant`, `Guardian`, `Assassin`, `Trickster`, `Saboteur`)만 포함(`id="Raider"`의 표시명은 `Warden`, 리그 전직 `ascendancyName="Warden"`은 자동 배제).
  3. **클래스명·시작점**: `tree["classes"][classId]["name"]`으로 클래스명 매핑(시작 노드 `name`의 `"Seven"`/`"SIX"` 미사용).
  4. **시각 간선(`visualEdges`)과 규칙 그래프(`adjacency` + `classStartNeighbors`) 분리**:
     - `out`과 `in` 양쪽을 모두 읽어 같은 소속(`ascendancyName` 동일)의 양방향 연결을 수집(**Scion `58833` 등 `in` 전용 시작 노드 누락 방지**).
     - `classStart` 노드는 일반 `adjacency` 정점에서 제외하고 `classes[classId].startNeighbors` 배열로 별도 저장 → **타 클래스 시작점을 경유하는 우회·할당 악용 원천 차단**.
     - `isMastery` 노드는 경로 통과 간선(`adjacency`)에서 제외하고, `masteryGroupNotables[groupId] = [notableIds...]` 매핑을 생성.
     - 7개 클래스 시작점 및 19개 전직 시작점에서 BFS 도달 불가한 비마스터리 고립 노드(금지된 화염/살점 전용 7개 등)를 자동 제외하고 `test_tree_compiler.py`에서 0건 단언.
  5. **다중 선택 허브(`isMultipleChoice` / `isMultipleChoiceOption`) 보존**:
     - PoB 3.30의 허브 7개(Ascendant 6 + Assassin 1)와 선택지 20개에 `isMultipleChoice: true`, `isMultipleChoiceOption: true`, `choiceParentId: <hubId>` 기록.
     - `grantedPassivePoints`(Ascendant 18개 노드) 및 `grantsClassStart`(Scion `Path of the ...` 6개 노드) 메타데이터 보존.
  6. **멀티라인 `stats` 정규화 & 정규화 `masteryEffects` 테이블**:
     - `stats` 배열의 각 문자열에 포함된 `\n`을 컴파일 단계에서 개별 줄로 분할(84개 노드 + 26개 마스터리 효과).
     - 한글 CSV는 반드시 `csv.reader(..., newline="")`로 파싱해 따옴표 안 개행과 `" / "` 연결을 정확히 매칭.
     - `masteryEffects`는 최상위 정규화 사전(`effectId -> { stats, statsKo }`, 고유 353개)으로 빼고 마스터리 노드에는 `effectIds: [u32...]`만 저장해 중복 5.2배 제거.

### S3-M2. 패시브 트리 그래프 & 규칙 엔진 (`PassiveTreeData`, `PassiveTree`)
- **순수 C++ 코어 (`skyrimpoe_core`, 엔진 비의존)**:
  - `PassiveTreeData::LoadFromFile`: C++에서 불필요한 좌표·원호·한글 필드를 건너뛰고 그래프·클래스·전직·마스터리·영문 `stats`만 경량 파싱해 `kDataLoaded` 지연을 최소화.
  - **포인트 단일 진실 원천 (검수 C7 반영)**:
    - `ComputeAvailableNormalPoints(exileLevel, bonusPassivePoints)`와 `ComputeAvailableAscendancyPoints(ascendancyPointsEarned)`는 **부호 있는 `std::int32_t`**로 계산:
      - `availNormal = (exileLevel - 1) + bonusPassivePoints + grantedPassivePointsFromAllocated - spentNormalPoints`
      - `availAsc = ascendancyPointsEarned - spentAscendancyPoints`
    - INI 보너스 축소 등으로 음수가 되더라도 부호 없는 정수 언더플로(42.9억)를 방지하고, `avail <= 0`이면 신규 할당만 거절·회수는 항상 허용.
    - `PersistentState::unallocatedPassivePoints`는 `'CORE'` 하위 호환 직렬화 미러(`static_cast<uint32_t>(std::max(0, availNormal))`)로만 동기화.
  - **다중 선택 허브 규칙 (검수 C2 반영)**:
    - `isMultipleChoice` 허브는 0포인트(직접 단독 할당 불가).
    - `isMultipleChoiceOption` 할당 시: ① 부모 허브가 현재 전직 할당 집합에 연결되어 있고, ② 같은 `choiceParentId`의 다른 옵션이 아직 미할당이며, ③ `availAsc >= 1`일 때 허용. 할당 시 부모 허브는 통과 가능한 가상 노드(`allocatedHub`)로 취급.
    - `isMultipleChoiceOption` 회수 시: 부모 허브 너머의 후속 노드(예: `Passive Point` → `Path of the Marauder`)가 남아 있으면 연결성 검사에서 단절로 판정해 거절.
  - **연결성 & 최단 경로 BFS (검수 C3, M3 반영)**:
    - 일반 트리 출발 시드 집합 = `classStartNeighbors[classId] ∪ { classStartNeighbors[c] | allocated Ascendant Path-of-the-c node }`.
    - 전직 트리 출발 시드 = `ascendancyStartNode(ascendancyId)` (전직 선택 시 0포인트 자동 할당).
    - `AllocatePath(nodeIds)`: 경로의 모든 미할당 노드를 순차 검증(허브 0점, 옵션 단일 선택, 마스터리 제외)해 필요 포인트 총합 ≤ 가용 포인트일 때 원자 적용.
    - `RefundNode(nodeId)`: 시작점 직접 회수 불가. 제거 후 남은 모든 일반 노드가 남은 일반 시드에서 도달 가능하고, 남은 모든 전직 노드가 전직 시작점에서 도달 가능하며, `grantedPassivePoints` 감소 후에도 `availNormal >= 0`이어야 허용. 주요 패시브 회수로 해당 마스터리 그룹의 할당된 주요 패시브가 0개가 되면 연결된 마스터리도 같은 트랜잭션에서 자동 회수(결정 153 ①).
    - `RefundAll(ascendancyOnly)`:
      - `ascendancyOnly == false`: 모든 일반·마스터리·전직 소비 노드와 마스터리 일괄 회수(클래스 재선택 가능 상태로 복귀).
      - `ascendancyOnly == true`: 전직 노드만 제거했을 때 **주 `classStart` 단독 시드로 일반 트리 전체가 연결 유지되고 `availNormal >= 0`**인 경우에만 허용(위반 시 사유 반환 및 전체 회수 안내, 검수 M3).
    - `SelectClass(newClassId)`: `!classSelected`이거나 소비 노드(일반+마스터리+전직)가 0개일 때만 허용, 전직 함께 초기화(결정 153 ②).
    - `SelectAscendancy(newAscId)`: `classSelected && ascendancyPointsEarned >= 2`, 현재 클래스 소속 19종 중 하나, 기존 전직 소비 노드 0개일 때 허용.
