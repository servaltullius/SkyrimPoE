# 패시브 트리 브라우저 미리보기

저장소 루트에서 `python tools/ui-preview/serve.py --port 8000`을 실행합니다. [PoE2 트리](http://127.0.0.1:8000/?game=poe2) 또는 [PoE1 트리](http://127.0.0.1:8000/?game=poe1)를 열고, 서버는 `Ctrl+C`로 닫습니다. 미리보기는 페이지마다 새 상태로 시작합니다. 가짜 브리지가 패시브 포인트와 후회의 오브를 갱신하며, 우측 전투 스탯은 예시 값입니다.

- **경로와 능력치** · 레인저 또는 헌트리스를 고르고 `#1140`을 검색한 뒤 ‘다음’을 누릅니다. 중앙 노드를 좌클릭하고 힘·민첩·지능 중 하나를 고릅니다. 할당한 노드를 다시 누르면 변경 비용을 확인할 수 있습니다. 무료 회수 모드는 URL에 `&freeRefund=1`을 붙입니다.
- **조건부 잠금** · 드루이드의 오라클을 고른 뒤 `#479`를 찾습니다. 노드에 마우스를 올려 요구 조건을 확인하고, `#5571`을 할당한 뒤 잠금이 풀리는지 확인합니다.
- **변형과 주얼** · 위치를 고르고 리치와 심연의 리치에서 `#17788`의 툴팁을 비교합니다. 경로를 할당한 뒤 이 노드를 다시 클릭하면 소켓에 예시 주얼을 장착하거나 회수할 수 있습니다.
- **회수와 검색** · 노드·스탯을 한글 또는 영문으로, 특정 노드를 `#번호`로 검색합니다. 우클릭으로 노드를 회수하고, 후회의 오브 비용이 있으면 3.5초 내에 한 번 더 우클릭해 확정합니다.

클래스를 고른 뒤 브라우저 콘솔에서 `await poePreview.measure()`를 실행하면 패닝과 확대·축소를 재생합니다. URL에 `&benchmark=1`을 붙이면 레인저로 시작해 자동으로 측정합니다. 평균 프레임 간격과 가장 느린 1%의 평균 간격을 각각 유휴 상태의 같은 지표와 비교합니다. 콘솔에는 유휴 중 다시 그리기 횟수와 그리기 콜백 소요 시간(ms)도 출력됩니다. 결정 61의 기준은 평균 증가량 +8ms, 가장 느린 1% 증가량 +17ms, 유휴 중 다시 그리기 0회입니다. 브라우저 측정값에는 Skyrim과 Prisma UI의 실행 시간이 포함되지 않습니다.

## C++·JS 일치 시험

`POE_PLUGIN_BUILD_ROOT`를 지정하고 `vs2022-release-local` 프리셋으로 빌드한 뒤 저장소 루트 PowerShell에서 실행합니다. 직접 실행 파일을 지정하려면 `POE_PLUGIN_TEST_EXE`를 설정합니다.

```powershell
python -m pytest -rs tools/compiler/test_tree_poe2.py -k cpp_js_parity
```

pytest가 C++ 실행 파일로 픽스처를 만든 뒤 Node.js에서 비교합니다. Node.js가 없으면 건너뛴 이유를 표시합니다. 두 실제 팩에서 경로, 할당·회수 결과와 비용, 절대 포인트, 마스터리 해금, 선택 제약, 노드 변형과 주얼 배율을 비교합니다. 최저 비용이 같은 시작 경로가 여럿인 사례는 C++에서 같은 비용으로 할당된 각 경로와 결과를 비교합니다.

## PoE2 트리 재생성

`python tools/compiler/rebuild_tree_poe2.py --tests <skyrimpoe_tests.exe>`로 PoB 원천과 한국어 클라이언트 표에서 팩과 보고서를 생성합니다. 원천 위치를 바꾸려면 `--pob`, `--game`을 지정합니다. `--check`는 다시 생성한 네 파일을 저장소의 파일과 바이트 단위로 비교합니다.
